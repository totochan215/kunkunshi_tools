# Scans Nomura-ryu — retirés du dépôt (droits d'auteur)

Ce dossier ne contient plus les PDF de scans du recueil imprimé
« 琉球流工工四上巡り » (réédition scannée de planches calligraphiées, ~1930,
édité par Paris Sanshin Club). Ils étaient présents par erreur et ont été
retirés : le recueil est soumis au droit d'auteur.

Les mesures de calibrage dérivées de ces scans (géométrie du layout
Nomura-ryu) restent consignées dans `AGENTS.md`, section « Constantes de
calibrage mesurées sur les scans Nomura-ryu ».
